::Q1 Store-and-Forward vs Packets::
Why did packet switching replace store-and-forward networking?
{
=It allows multiple messages to share the same connection efficiently
~It guarantees faster hardware
~It eliminates the need for routing
~It prevents all delays
}

::Q2 Packet Independence::
If packets take different paths to the destination, what problem does this design solve?
{
=It avoids single points of failure in the network
~It ensures packets arrive in order
~It reduces packet size
~It eliminates routing tables
}

::Q3 Reassembly Insight::
Why must the destination reassemble packets rather than the network?
{
=The network is designed to stay simple and not track full messages
~Routers do not have enough power
~Packets cannot be numbered
~The link layer prevents reassembly
}

::Q4 Layering Strategy::
Why is the networking problem divided into layers instead of solved as one system?
{
=It allows independent improvement of different parts of the system
~It reduces the number of computers needed
~It eliminates the need for protocols
~It guarantees perfect reliability
}

::Q5 Link Layer Scope::
Why does the link layer only handle one hop instead of end-to-end communication?
{
=Limiting scope makes the problem manageable and efficient
~It ensures global addressing
~It avoids packet loss
~It replaces higher layers
}

::Q6 Shared Medium Behavior::
Why do Ethernet and Wi-Fi require rules like collision detection?
{
=Multiple devices share the same communication medium
~They operate at different voltages
~They use different IP addresses
~They require encryption
}

::Q7 MAC Address Limitation::
Why can MAC addresses not be used for global Internet routing?
{
=They only identify devices within a local network
~They change too often
~They are too large
~They are encrypted
}

::Q8 IP Design Philosophy::
Why does the Internet layer not guarantee delivery?
{
=Keeping it simple allows the network to scale globally
~It reduces the need for routers
~It improves security
~It speeds up DNS
}

~It ensures faster packet delivery
~It guarantees reliability
~It avoids packet collisions
}
